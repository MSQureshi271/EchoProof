# P2-05 PhonemeDF adapter

The adapter builds a new snapshot from the completed P2-04 inventory without reading audio. It includes genuine, XTTSv2, ChatterboxTTS, MeloTTS and VITS. The source paths and candidate labels come from the configured components and source registry. Every candidate remains unverified and pending admission; unsupported components and invalid inventory records are recorded as pending dispositions. Transcripts remain inventory inputs for P2-06. A matching filename does not establish identity or a split.

`raw_recordings.parquet` has the existing `Recording` envelope columns `schema_name`, `schema_version`, and `payload_json`. The JSON payload contains the recording fields. `mapping_evidence.jsonl` records candidate mapping, `dispositions.jsonl` records every input row, and `provenance.json` and `snapshot_manifest.json` record inputs, software and artifact hashes. Each run creates a new snapshot directory under `data/manifests/phase2_raw/`; the snapshot is never overwritten. Runs with invalid records require review. Inventory contents remain available at their original location.

The inventory was updated after the user reported deleting duplicate copies. The retained audio hashes were computed before that cleanup, and current audio bytes have not been independently rehashed. Preserve that limitation when interpreting the snapshot. The user has confirmed release and permission; no archive checksum comparison or formal admission is implied. ChatterboxTTS remains protected for proposed final evaluation.
