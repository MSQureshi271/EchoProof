# P1-08 baseline fixture probes

Run `python -m echoproof.cli probe lr --config configs/phase1.yaml` and `python -m echoproof.cli probe bigru --config configs/phase1.yaml`. Each command generates its own registered software fixtures and a unique run under `runs/phase1/`. It writes a feature schema, metrics, environment, checksum manifest and an explicitly disposable model. These runs and weights must never be used for research model selection, performance claims or deployment. Labels are arbitrary test values; the generated signals are not speech.

The shared extractor expects a finite mono waveform at 16 kHz. The handcrafted representation includes 13 MFCCs and their deltas with mean/std, centroid, bandwidth, rolloff, flatness, zero-crossing rate and RMS mean/std, plus voiced fraction and voiced F0 mean/std. It uses frame length 512, window 400, hop 160, 64 mel bands and no centering. Clips shorter than 512 samples are padded to one frame; one- or two-frame MFCC deltas are zero. Voicing is a fixture-stage YIN estimate gated by frame RMS and normalized autocorrelation. An unvoiced clip has a zero voiced fraction and missing F0 statistics; a training-fitted median imputer, retaining all-empty columns, handles missing values before standard scaling. Feature names and settings determine a schema hash. These policies are provisional until research preprocessing is defined.

The temporal representation is natural log mel power with 64 bins, FFT 512, window 400, hop 160, center disabled and floor `1e-10`. For valid sample count `n >= 512`, the valid frame count is `1 + floor((n - 512)/160)`; shorter audio is right-padded to 512 and yields one frame. Padding is added only after extracting valid frames. The GRU uses two bidirectional layers, 128 hidden units per direction, dropout 0.3, packed lengths, masked mean pooling and two logits. Fixture-only normalization statistics come from all frames in the generated fixture set and must never be reused for research data; future training must fit normalization on training data alone.

The LR probe saves and reloads its imputer/scaler/classifier pipeline and verifies class-1 scores. Its joblib file is trusted local probe output: never load an untrusted joblib or pickle file. The BiGRU probe compares single-item, batch and altered-padding outputs in evaluation mode within `1e-5`, performs one disposable AdamW step with dummy labels, checks finite loss and gradients, and checks reload parity within `1e-6`. The checks execute on CPU even if Colab provides a GPU. These checks do not establish training performance, GPU feasibility or full model adapter readiness for real speech.
