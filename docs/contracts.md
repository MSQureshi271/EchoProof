# EchoProof shared contracts, version 1

The implementation is in `src/echoproof/contracts.py`. These interfaces describe metadata and model boundaries for future work; they do not perform audio decoding, model training, or prediction. Use the same `InferenceResult` in the application and other consumers.

Metadata types are `Recording`, `SplitAssignment`, `Chunk`, `DecisionRule`, `BundleSpecification`, `PredictionRow`, and `InferenceResult`. Each persisted object carries `schema_version: 1`; `to_json()` uses sorted keys and rejects nonfinite numbers, and `from_json()` rejects missing or unknown fields. `write_parquet` and `read_parquet` use a versioned envelope with `schema_name`, `schema_version`, and canonical `payload_json` columns. The payload stores nested metadata and nulls without relying on Parquet's inference of all-null columns. Querying individual fields requires parsing the payload; future columnar exports must define and version their own physical schemas. These helpers require PyArrow and do not claim atomic storage or artifact checksums, which belong to P1-06.

The example under `tests/fixtures/contracts/` is fabricated metadata; its all-zero digest is a placeholder for a nonexistent fixture file, never a research checksum. Null means unknown identity or metadata; identifiers use a source namespace such as `fixture:recording-001`. Do not replace missing identities with a shared `unknown` value. Relative original paths use forward slashes and reject drive prefixes, absolute paths and traversal.

`Recording` permits a retained audit candidate with missing or unverified label/method. Explicit `label_verified` and `method_verified` flags distinguish candidates from established labels. Call `validate_supervised()` before using a recording for supervised fitting. Verification is a provenance claim made by the data audit, not something the schema can prove. `validate_relationships(..., supervised=True)` applies that check to assigned records and verifies unique recordings and assignments, parent references, consistent split metadata, group partition and validation-role boundaries, and chunk inheritance. The caller must supply the complete relevant collections; separate validation of a subset cannot prove global uniqueness or absence of leakage.

Chunk offsets are in the chunk's declared sample rate. `end_sample` is exclusive and represents actual valid audio; padded model size is `input_samples`. Seconds must match samples, and `valid_samples` equals the interval length. Identity links and grouping are still subject to data audit; matching stems alone are not proof.

`FeatureBatch` is an in-memory array or tensor contract, not JSON metadata. Call `.validate()` before consuming it. Fixed arrays are `[batch, features]`; temporal arrays are `[batch, time, features]` with right-padded lengths and Boolean masks. Only valid frames must be finite; all fixed features must be finite. IDs and optional binary labels must align. Arrays and tensors are not stored in the metadata envelope.

Scores are class-1 TTS probabilities. A `DecisionRule` is either `threshold`, using `score >= threshold`, or `all_negative` with a null threshold. This represents the all-negative policy without JSON infinity. For successful `PredictionRow` records, a calibrated score, when present, is the decision input; otherwise the raw score is used. Failure rows have no scores, decision, or prediction. `InferenceResult` has a score and assessment only on success; failures carry a reason. Coverage is bounded by decoded duration. A score is a model output and does not by itself establish calibration or certainty.

`ModelAdapter` describes immutable metadata, feature preparation, saving/loading and ordered `ChunkScore` outputs. Implementations must expose metadata as a read-only mapping and call `validate_chunk_scores` against the requested IDs; numerical shape alone cannot prove correspondence. `RecordingPredictor` specifies bytes plus a validated `BundleSpecification` returning `InferenceResult`. The bundle specification fixes the label mapping, preprocessing hash and decision rule, but it does not yet load or validate model weights. Actual adapter implementations and production bundle checks are later work.
