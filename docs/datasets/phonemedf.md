# PhonemeDF source card

The current project uses the genuine recordings and four TTS families in the user-reported Zenodo PhonemeDF 1.0.1 release. The user reports permission for the downloaded dataset; the publisher metadata identifies CC BY 4.0, and underlying terms still require review. ChatterboxTTS remains protected as the proposed final unseen family. Voice-conversion components are outside the TTS task.

Run the unified [P2-07 to P2-09 workflow](../p2_07_09_execution.md) for actual header, sample and reconciliation outcomes. Each P2-08 run writes a dated, data-backed `phonemedf.md` source card alongside its `reconciliation.json` in `reports/phase2/p2_08-<run-id>/`. That run-specific card is the source for measured counts and unresolved findings.
